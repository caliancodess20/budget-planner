# Budget Planner

A simple command line budget planner app built with Python.

## Features
- Add budget categories with spending limits
- Log daily expenses with descriptions
- View budget summary with percentage used
- Spending alert when 80% budget is used
- Over budget alert when limit is exceeded
- Track monthly savings
- View savings history
- Data saved automatically to a JSON file

## How to run

Make sure Python is installed on your computer.

Open PowerShell and navigate to the project folder:

cd budget_planner

Run the app:

python budget_planner.py

## How to use

1. Choose option 1 to add a budget category
2. Choose option 2 to log an expense
3. Choose option 3 to view budget summary
4. Choose option 4 to track savings
5. Choose option 5 to view savings history
6. Choose option 6 to exit

## Built with
- Python 3
- JSON for data storage
